# adclip v0.3 — `ClaudeCliProvider` Design Spec

**Date:** 2026-04-18
**Status:** Approved design, pending implementation plan
**Builds on:** v0.2.1 (tag on `main`)

## Purpose

Eliminate the ambiguity that caused three separate Claude Code sessions to propose workarounds ("deploy agents to replace the API") when no `ANTHROPIC_API_KEY` was present. The root cause: adclip's CLI default provider was `AnthropicProvider`, which raises on missing key. Agents reading the code reasonably inferred they needed to rewrite the LLM layer rather than use the already-existing no-key path (MCP sampling).

v0.3 makes "adclip never needs an API key" true by construction — not just in the MCP path.

## Goals

1. **CLI no longer requires any API key.** `adclip run brief.json` works out of the box under subscription auth.
2. **Keyless path is the visible default.** `--llm` defaults to `claude-cli`, not `anthropic`.
3. **Agents reading the codebase don't invent workarounds.** `CLAUDE.md` at repo root explains the no-key philosophy; the `AnthropicProvider` error points them to the right path.
4. **MCP path keeps working via sampling** (v0.2 behavior unchanged).

## Non-goals

- Optimizing subprocess startup cost. Each `claude -p` invocation costs ~5-10s; a 16-call brief pays that latency 16 times. Acceptable for v0.3; batching or a long-running daemon is v0.4 if pain emerges.
- Replacing `AnthropicProvider`. It stays as an optional faster path for users with a key.
- Supporting non-Claude CLIs (OpenAI, etc.).

One new module, edits in four existing files, one new test file, one new CLAUDE.md.

## ClaudeCliProvider interface

```python
class ClaudeCliProvider:
    """Shells out to the `claude` CLI in non-interactive mode. No API key —
    uses the user's existing Claude Code subscription auth.

    One subprocess per generate() call. Startup ~5-10s per call.
    """

    def __init__(
        self,
        model: str = "sonnet",
        timeout: float = 90.0,
        claude_path: str = "claude",
    ):
        self._model = model
        self._timeout = timeout
        self._claude = claude_path

    async def generate(self, prompt: str, n: int) -> str:
        proc = await asyncio.create_subprocess_exec(
            self._claude, "-p",
            "--output-format", "text",
            "--no-session-persistence",
            "--tools", "",
            "--model", self._model,
            "--append-system-prompt",
            "You are a non-interactive worker. Return JSON only. "
            "Do not use any tools. Do not ask questions.",
            prompt,
            stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.PIPE,
        )
        stdout, stderr = await asyncio.wait_for(
            proc.communicate(), timeout=self._timeout
        )
        if proc.returncode != 0:
            raise RuntimeError(
                f"claude CLI failed (rc={proc.returncode}): "
                f"{stderr.decode()[:500]}"
            )
        return stdout.decode()
```

**Rationale for specific flags:**

- `-p` / `--print`: non-interactive, prints result, exits
- `--output-format text`: plain text output; downstream `parse_copy_candidates` / `parse_judge_response` already tolerate prose wrapping via the JSON regex
- `--no-session-persistence`: don't save these one-shot calls to the resume history
- `--tools ""`: subprocess shouldn't call tools; it's a text-in/text-out worker
- `--model sonnet`: fast/cheap; Opus is overkill for copywriting + judge scoring
- `--append-system-prompt "…Return JSON only. Do not use any tools. Do not ask questions."`: reinforces the non-interactive worker role and JSON-only output discipline

**Rationale for NOT used:**
- `--bare`: explicitly requires `ANTHROPIC_API_KEY` per `--bare` docs; defeats the keyless purpose
- `--json-schema`: would be cleaner but requires per-provider schema awareness; text + tolerant parsing is simpler for v0.3
- `--dangerously-skip-permissions`: we pass `--tools ""` so there's nothing to permit; this flag is unnecessary

## Changes to `default_provider()` and `AnthropicProvider`

```python
# llm.py
def default_provider() -> LLMProvider:
    """Return the default non-MCP provider. Keyless by construction."""
    from adclip.claude_cli import ClaudeCliProvider
    return ClaudeCliProvider()


class AnthropicProvider:
    def __init__(self, model: str = "claude-sonnet-4-6"):
        import anthropic

        if not os.environ.get("ANTHROPIC_API_KEY"):
            raise RuntimeError(
                "AnthropicProvider requires ANTHROPIC_API_KEY, which this "
                "project normally does not use. Keyless alternatives: "
                "(1) use MCP sampling via Claude Code (see .mcp.json), or "
                "(2) use ClaudeCliProvider (default on the CLI). "
                "See CLAUDE.md in the repo root for details."
            )
        self._client = anthropic.Anthropic()
        self._model = model
```

## CLI changes (`src/adclip/cli.py`)

```python
@main.command("copy")
@click.argument("brief_path", type=click.Path(exists=True))
@click.option(
    "--provider",
    default="claude-cli",
    type=click.Choice(["claude-cli", "anthropic", "fake"]),
)
def copy_cmd(brief_path: str, provider: str) -> None:
    """Generate ad copy (no images/video).

    Providers:
      claude-cli (default): shells out to `claude -p`. No API key needed.
                            Uses your Claude Code subscription auth.
      anthropic:            direct Anthropic API. Requires ANTHROPIC_API_KEY.
                            ~3x faster per call (no subprocess spin-up).
      fake:                 deterministic stub, for tests.
    """
    out = asyncio.run(_generate_copy_impl(
        Path(brief_path).read_text(), provider_name=provider
    ))
    click.echo(json.dumps(out, indent=2))
```

Same pattern for `run_cmd` with `--llm`.

## MCP tool changes

`_get_provider` / `_resolve_llm` gain a `"claude-cli"` branch:

```python
def _get_provider(name: str, *, session=None) -> LLMProvider:
    if name == "fake":
        return FakeLLMProvider()
    if name == "sampling" or name == "default":
        if session is None:
            raise RuntimeError(
                "sampling provider requires an MCP session. Try --llm "
                "claude-cli if no sampling-capable client is connected."
            )
        return SamplingLLMProvider(session)
    if name == "claude-cli":
        from adclip.claude_cli import ClaudeCliProvider
        return ClaudeCliProvider()
    if name == "anthropic":
        return AnthropicProvider()
    raise ValueError(f"Unknown provider: {name}")
```

(Note: `default_provider()` now returns `ClaudeCliProvider`, so the `"anthropic"` branch must instantiate `AnthropicProvider` directly rather than calling `default_provider()`.)

MCP tool default remains `"default"` which stays `SamplingLLMProvider` when a session is present. `"claude-cli"` is the fallback for MCP clients that don't support sampling.

## `CLAUDE.md` at repo root

Purpose: any Claude Code session that enters `~/Desktop/adclip/` auto-loads this file and stops proposing API-key workarounds.

```markdown
# CLAUDE.md — adclip project context

## No API key, by construction

adclip never requires `ANTHROPIC_API_KEY`. Any runtime error mentioning a
missing key means the wrong provider got instantiated. **Do not add the key
as a workaround.** Do not write code that reads it. Do not rewrite the
LLM layer.

## The three LLM provider paths

1. **MCP sampling** (`SamplingLLMProvider`) — when adclip runs as an MCP
   server under Claude Code. The host client runs LLM completions on
   adclip's behalf. No key. This is the default for MCP tools.

2. **Claude CLI subprocess** (`ClaudeCliProvider`) — when adclip runs via
   its CLI (`adclip run`, `adclip copy`). Shells out to `claude -p` using
   the user's subscription auth. No key. Default for the CLI.

3. **Direct Anthropic API** (`AnthropicProvider`) — opt-in only, for users
   with a key who want ~3x faster per-call latency. Never a default.

## Testing

Use `--llm fake` / `provider_name="fake"` in tests. `FakeLLMProvider` is
deterministic and sync-safe via `asyncio.run`.

## If you hit an LLM error

- "ANTHROPIC_API_KEY not set": you instantiated `AnthropicProvider`
  somewhere. Replace with `default_provider()` or `ClaudeCliProvider()`.
- "sampling provider requires an MCP session": you're outside an MCP
  session (e.g., CLI context). Use `ClaudeCliProvider` or pass `--llm
  claude-cli` explicitly.
- "claude CLI failed": check `which claude` and that subscription auth
  is active (`claude -p "hello"` should return a response).

## Scope for contributors

- Static ads + text ads only (v0.1)
- Self-review loops: judge + heal (v0.2)
- Keyless CLI via claude subprocess (v0.3)
- Video pipeline, modular DCO, adversarial critic: deferred (see v0.x plans)
```

## Testing strategy

`tests/test_claude_cli_provider.py`:

1. **Argv shape** — mock `asyncio.create_subprocess_exec` to capture the argv tuple. Assert: has `-p`, `--output-format text`, `--no-session-persistence`, `--tools ""`, `--model sonnet`, `--append-system-prompt <something containing "JSON only">`, and the prompt as the last positional arg.
2. **Happy path** — mocked subprocess returns JSON-shaped stdout; `generate()` returns it verbatim. Downstream parsers (`parse_copy_candidates`) are tested separately.
3. **Failure propagation** — mocked subprocess returns non-zero returncode with stderr; `generate()` raises `RuntimeError` containing the stderr prefix.
4. **Timeout** — mocked `asyncio.wait_for` raises `asyncio.TimeoutError`; assert the exception bubbles up (or is wrapped cleanly, depending on what the implementer picks — spec accepts either).

No test runs the real `claude` binary. Integration smoke test is manual: `.venv/bin/adclip run examples/taichi_brief.json` should produce real output without any env vars.

Existing tests unchanged:
- All `FakeLLMProvider`-based tests stay green (no provider change affects them).
- `AnthropicProvider` tests are untouched (if any; current suite has none — it was gated on env var).

## Migration

None needed. Users previously setting `ANTHROPIC_API_KEY` keep working by passing `--llm anthropic`. Default behavior changes silently, which is fine — the old default required a key the user likely didn't have.

## Deferred

- `--json-schema` output enforcement (cleaner than prose+regex, but per-provider schema definition needed).
- Long-running `claude` daemon / batch subprocess for latency reduction.
- Opus option on ClaudeCliProvider — current is Sonnet; add `--model` CLI passthrough in v0.3.1 if demand surfaces.
- Auto-detect sampling capability on MCP clients — fall back to `ClaudeCliProvider` automatically when sampling isn't supported.
