# Local-service lead generation

**Business goal:** generate same-day service bookings.  
**Audience:** homeowners in the Phoenix metro area with an AC problem.  
**Channels:** Google Search and Meta.  
**Primary message question:** does urgency/problem language outperform generic availability language?

This example is intentionally ordinary. It demonstrates that adclip is useful for the high-volume lead-generation work agencies and local businesses run every day, not only for polished national brands.

Run locally:

```bash
adclip run examples/03-local-service-lead-gen/brief.json \
  --text-provider fake \
  --image-provider fake
```

The same pattern can be adapted to roofing, plumbing, dental, legal, landscaping, auto repair, and other local-service categories while keeping geographic, claim, and CTA constraints explicit.
