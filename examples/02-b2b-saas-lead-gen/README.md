# B2B SaaS lead generation

**Business goal:** book qualified product demos.  
**Audience:** marketing directors at 50–500 employee B2B SaaS companies.  
**Channels:** LinkedIn and Google Search.  
**Primary message question:** does revenue-proof framing outperform time-savings framing?

This example shows that adclip can preserve one campaign thesis while adapting the expression to very different ad surfaces.

```text
Google Search:
  high-intent, explicit category/problem language

LinkedIn:
  executive problem framing and business context
```

Run locally:

```bash
adclip run examples/02-b2b-saas-lead-gen/brief.json \
  --text-provider fake \
  --image-provider fake
```

The brief deliberately includes both operational and financial angles so a marketer can use controlled variants rather than asking every channel to repeat the same headline.
