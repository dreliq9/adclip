# Mobile app acquisition

**Business goal:** drive free-trial starts.  
**Audience:** adults trying to build consistent daily habits without a complicated planning system.  
**Channels:** TikTok, Reels, YouTube Shorts, and Meta Feed.  
**Primary creative question:** does concrete routine framing outperform generic motivation framing?

This example gives the video-routing system a recognizable performance-marketing use case.

Run locally:

```bash
adclip run examples/05-mobile-app-acquisition/brief.json \
  --text-provider fake \
  --image-provider fake \
  --video-provider fake
```

Useful route comparisons for this campaign:

```text
draft       cheap concept exploration
general     standard social creative
multi-shot  narrative / routine progression
premium     hero creative when justified
```

The point is not that one model is always best. adclip keeps the campaign intent stable while the route/provider/model can change.
